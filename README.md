# Retro-GRWM
Retro GRWM is a nostalgic 80s/90s-inspired web application that combines a vintage cassette player aesthetic with an interactive Get Ready With Me (GRWM) experience.
✨ Features
📸 Live camera access
🔄 Front/rear camera switching
📷 Capture GRWM photos
🎵 Add and store personal music
💾 Persistent music library using IndexedDB
▶️ Play, pause, next & previous controls
📊 Music progress and volume controls
📻 Retro 80s/90s cassette-player UI
💿 Animated vintage-inspired interface
📱 Responsive web design
🛠️ Built With

HTML • CSS • JavaScript • Web Camera API • Canvas API • IndexedDB • HTML5 Audio

A small nostalgic web experience bringing the charm of retro music players into a modern GRWM experience. 🎀📻📸
